Core design goals

Four principles, no compromises

Every line of ONCRIX is written against the same four goals — enforced by Rust's type system and a minimal trusted computing base.

// stability

Stable

Rust memory safety, no undefined behavior, and graceful panic handling — no null, no data races.

// security

Secure

Capability-based access control, privilege separation, and a minimal trusted computing base.

// extensibility

Extensible

Modular microkernel design — user-space drivers and services, with a plugin architecture.

// performance

Fast

Zero-cost abstractions, lock-free data structures, efficient IPC, and minimal context switches.

Architecture

A true microkernel

The kernel keeps only the essentials — scheduling, memory, and IPC. Drivers, filesystems, and services live in user space and talk through message passing.
